# Школа Корана — учёт учеников, посещаемости, хифза и оплат

Веб-приложение для небольшой школы Корана: сначала телефон, но так же удобно с компьютера.

## Запуск

```bash
python3 app.py
```

Откройте <http://localhost:8420>. Нужен только Python 3.8+ (на macOS он уже есть) — ни пакетов, ни внешних
сервисов, ни ключей. При первом запуске создаётся база `data/school.db` с демо-данными.

Открыть с телефона в той же сети Wi‑Fi:

```bash
HOST=0.0.0.0 python3 app.py
```

Сервер напечатает адрес вида `http://192.168.x.x:8420`. По умолчанию приложение доступно только с этого
компьютера — так безопаснее, пока включён демо-вход без пароля.

| Переменная | Что делает | По умолчанию |
|---|---|---|
| `PORT` | порт | `8420` |
| `HOST` | адрес (`0.0.0.0` — пускать из локальной сети) | `127.0.0.1` |
| `DEMO_LOGIN` | `0` — убрать кнопки быстрого демо-входа | `1` |
| `SCHOOL_DB` | путь к файлу базы | `data/school.db` |

## Демо-входы

На экране входа четыре кнопки: владелец **Абдуллах**, администратор **Марьям**, учитель **Юсуф**,
учительница **Аиша**. Вход по логину и паролю тоже работает; логины и тестовые пароли лежат в `seed.py`
(`DEMO_USERS`). Перед настоящей работой смените их и запустите с `DEMO_LOGIN=0`.

## Кто что видит

| | Владелец | Администратор | Учитель |
|---|---|---|---|
| Главный экран школы | да | да (без зарплат) | свой: уроки сегодня и свои группы |
| Ученики, группы | все | все | только свои |
| Посещаемость, хифз | да | да | только свои группы и ученики |
| Оплаты, должники, семьи, заявки | да | да | нет |
| Зарплата учителей, настройки, журнал | да | нет | нет |
| Бесплатное обучение ученику | назначает | нет | нет |

Права проверяются на сервере для каждого запроса (`app.py`, параметр `roles` у маршрута и функции
`get_group` / `get_student`), а не только прячутся в интерфейсе.

## Правила, зашитые в систему

- **Мальчики — только в мужские группы, девочки — только в женские.** Проверка на сервере при любом способе
  записи: из заявки, из карточки ученика, при создании ученика.
- **Семейная скидка считается сама:** второй ребёнок −20%, третий и далее −30% (меняется в настройках).
  Первым считается тот, кто раньше пришёл в школу. Одна семья = один телефон родителя.
- **Начисления** создаются раз в месяц на каждую запись в группу; оплата привязана к начислению, поэтому
  долг виден по каждому ребёнку и месяцу. Частичная оплата разрешена, переплата — нет.
- **Джуз закончен**, когда сданы все суры, которые в него входят. Прогресс в процентах — по числу аятов
  сданных сур из 6236.
- **Зарплата учителя:** ставка за проведённый урок (урок считается проведённым, когда отмечена
  посещаемость) либо процент от оплат, поступивших за его группы в этом месяце.
- **Ничего не удаляется.** Ученики, группы, учителя уходят в архив; платежи и выплаты отменяются со
  статусом и причиной; снятая отметка о суре остаётся в базе. Все действия пишутся в журнал.

## Проверка сценариев приёмки

```bash
python3 acceptance_test.py
```

Поднимает отдельный сервер на временной базе и проходит сценарии заказчика через настоящий HTTP.
Рабочую базу не трогает.

## Демо-данные заново

```bash
python3 seed.py --reset
```

Прежняя база не стирается, а переименовывается в `data/school.db.<дата>.bak`. Даты демо-данных считаются от
сегодняшнего дня: посещаемость и оплаты всегда «за последние три месяца».

## Что где лежит

| Файл | Содержимое |
|---|---|
| `app.py` | HTTP-сервер, маршруты API, проверка ролей |
| `core.py` | правила: начисления и скидки, хифз, пропуски подряд, зарплата |
| `db.py` | схема SQLite и доступ к базе |
| `quran.py` | 114 сур, аяты, границы джузов |
| `seed.py` | демо-данные |
| `static/` | интерфейс: `app.js` (каркас), `pages.js`, `pages2.js` (страницы), `app.css` |
| `acceptance_test.py` | автоматическая проверка сценариев приёмки |
